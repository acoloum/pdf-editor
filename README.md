# 墨頁 PDF

供 Windows 11 x64 使用的本機 PDF 編輯器，支援在頁面內直接修改或新增文字、Delete 刪除後原位輸入、拖曳文字、頁面平移、表格文字置中、原生螢光標記／底線／文字註解、註解選取刪除與螢光改色、PNG 圖章、手寫或圖片簽名、圖章與簽名四角拖曳縮放、單頁或多頁縮圖拖曳排序、多選頁面批次移動／旋轉／複製／拖曳裁切／刪除、新增空白頁、插入外部 PDF、抽取選取頁面、頁碼、文字或圖片浮水印、可保存的頁首頁尾範本，以及 PDF 合併及拆分。文件只在本機處理，不需帳號或付費服務。

使用方式與限制見 `docs/使用說明.md`，可重現的建置步驟見 `docs/建置說明.md`，第三方授權見 `licenses/第三方元件清單.md`。

本專案因使用 PyMuPDF，以 AGPL-3.0 原始碼形式提供，適用於自用或公司內部部署；修改或再散布前請閱讀 `licenses/` 內的完整條款。
