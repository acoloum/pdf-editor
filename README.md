# 墨頁 PDF

供 Windows 11 x64 使用的本機 PDF 編輯器，支援在頁面內直接修改或新增文字、Delete 刪除後原位輸入、拖曳文字、頁面平移、繁中及英文 OCR、全文搜尋、三欄頁面像素比較、適合頁面或寬度縮放、表格文字置中、原生螢光標記／底線／文字註解、PNG 圖章、手寫或圖片簽名、多頁批次移動／旋轉／複製／拖曳裁切／刪除、插入及抽取頁面、輸出 PNG、頁碼、浮水印、頁首頁尾範本，以及 PDF 合併及拆分。文件與 OCR 全程只在本機處理，不需帳號或付費服務。

選取掃描頁後按「OCR 文字辨識」，程式會以內建 `chi_tra+eng` 模型加入不可見、可搜尋的文字層；已有足夠文字的頁面會自動跳過。「頁面比較」會把目前工作階段頁面與另一份 PDF 的指定頁以 144 DPI 比對，通道差異大於 24 的像素以半透明紅色標示。比較為唯讀操作，不改變 PDF 或復原歷史。

使用方式與限制見 `docs/使用說明.md`，可重現的建置步驟見 `docs/建置說明.md`，第三方授權見 `licenses/第三方元件清單.md`。

本專案因使用 PyMuPDF，以 AGPL-3.0 原始碼形式提供，適用於自用或公司內部部署；OCR 另含 MIT 的 tesserocr、LGPL-3.0-or-later 的 cysignals、Apache-2.0 的 Tesseract 與 tessdata_fast，以及 BSD-2-Clause 的 Leptonica。修改或再散布前請閱讀 `licenses/` 內的完整條款。
