# 墨頁 PDF 0.11.0

供 Windows 11 x64 使用的本機 PDF 編輯器。文件不會上傳，也不需帳號。

## 安裝與啟動

執行安裝程式，安裝至目前使用者的程式目錄。從開始功能表開啟「墨頁 PDF」。也可將 PDF 路徑當作程式命令列參數開啟。

## 修改文字

1. 按「開啟 PDF」並選擇文件。
2. 在中央頁面點選一個橫排文字區段。
3. 綠框輸入欄會直接出現在原文字位置；輸入新內容後按 `Enter`，或點到欄位外，就會立即寫入頁面。
4. 按 `Esc` 取消本次輸入。把內容清空後按 `Enter` 或點到欄位外，即刪除該段文字。
5. 右側可調整字級、文字框、字型、顏色，以及「靠左／水平置中／水平及垂直置中」。選擇格式後會直接套用，不需再按確認按鈕。
6. 若原字型缺少新輸入的字，程式會自動改用內建繁中文字型。
7. 按「另存新檔」，原始 PDF 保留。

選取文字後按 `Delete` 可清空該段文字；頁面原位置會立即出現輸入欄，可直接輸入替代內容。也可按工具列「新增文字」或 `Ctrl+T`；按鈕保持選取且頁面顯示綠色提示時，點選空白儲存格或頁面位置，中央頁面會出現輸入欄。按 `Esc` 可取消新增模式或目前輸入。所有已套用的操作都可用 `Ctrl+Z` 復原。

按住文字拖曳會立即移動並套用文字；按住頁面空白處拖曳可平移頁面。選取表格文字時，程式會自動使用偵測到的儲存格範圍作為文字框，並預設水平及垂直置中。部分 PDF 會把每個中文字拆成不同字型片段，本版會將同一行片段合併成可編輯文字，避免修改時與原字誤判重疊。

文字框的單位是 PDF 點（72 點為 1 英吋）。文字過長會被拒絕；可擴大文字框或減小字級。文字框不能與其他文字重疊。此版本支援局部橫排文字，直排、斜向字、無法解碼的字，以及原有未套用遮蔽標記的頁面不支援修改。

## 圖章與簽名

「蓋章」匯入透明 PNG，亦可匯入簽名 PNG；「手寫簽名」提供滑鼠書寫。按「常用圖章」可重用已收藏圖章。

加入圖章或簽名後，選取項目會出現外框及四個角落控制點。拖曳圖章本體可移動位置；拖曳任一角落控制點可直接放大或縮小，並自動維持原始長寬比例。放開滑鼠後會立即套用並同步更新右側數值，不需手動輸入長度與寬度。右側欄位保留作為精確位置、尺寸及旋轉角度的微調工具。

圖章會自動收藏；手寫簽名只有勾選收藏才永久保存。簽名是頁面外觀，不是憑證數位簽章。另存時圖章與簽名寫入 PDF 內容；重開後不保證可再次單獨選取它們。

## 頁面操作

先在左側縮圖選取頁面，再開啟工具列的「頁面操作」選單。按住 `Ctrl` 點選可逐頁加入或取消選取；先點第一頁，再按住 `Shift` 點另一頁，可選取連續範圍。選單可對全部選取頁面執行上移、下移、向左旋轉、向右旋轉、複製、裁切及刪除。批次移動會維持選取頁面彼此的順序，每次向指定方向移動一格。

選取單頁或多頁後，可在左側按住其中一個選取縮圖，直接拖曳到新位置。多頁會視為同一組移動，並維持彼此原有順序；放開滑鼠後，頁面順序、縮圖、目前頁碼及選取範圍會立即同步更新。

「複製選取頁面」會依照原順序建立副本，插入最後一個選取頁面之後，並自動選取新副本。快捷鍵依序為上移 `Alt+Up`、下移 `Alt+Down`、向左旋轉 `Ctrl+Shift+Left`、向右旋轉 `Ctrl+Shift+Right`、複製 `Ctrl+D` 及刪除 `Ctrl+Delete`。頁面操作可用 `Ctrl+Z` 復原或 `Ctrl+Y` 重做。文件至少必須保留一頁，因此選取全部頁面時不會啟用刪除。

選擇「直接拖曳裁切框」後，中央頁面會顯示綠色裁切框與八個控制點。拖曳任一邊線或四角，放開滑鼠便會把相同裁切範圍套用至進入模式時選取的全部頁面；按 `Esc` 可取消而不修改文件。拖曳框內部可整體移動目前裁切範圍。

需要指定固定數值時，可選擇「精確輸入裁切邊距」，輸入左、上、右、下邊距；單位是 PDF 點。裁切後寬度與高度至少保留 10 點。兩種裁切方式都只調整 PDF 的可見頁面範圍，原本位於範圍外的內容不會顯示，並可用 `Ctrl+Z` 復原。

若文件內還有可個別調整的圖章或簽名，頁面操作會先把它們固定至 PDF，再進行排序、旋轉或刪除，以避免位置錯亂。立即復原可回到圖章或簽名仍可個別調整的狀態。

## 頁碼與浮水印

先在左側選取要處理的頁面，再按工具列「頁碼／浮水印」。

「頁碼」可設定起始號碼、前置文字、後置文字、字級，以及頁首或頁尾的靠左、置中、靠右位置。非連續頁面會依目前選取頁面的先後順序連續編號。

「文字浮水印」可輸入文字並設定字級、不透明度及旋轉角度；程式使用內建繁中文字型產生置中的透明浮水印。「圖片浮水印」支援 PNG、JPG 及 JPEG，可設定相對頁面寬度、不透明度與旋轉角度，圖片會保持比例並置中。

頁碼與浮水印只套用至左側選取頁面，每次套用都會立即寫入目前工作階段，並可用 `Ctrl+Z` 復原。另存後會固定在 PDF 頁面中，重新開啟時不保證能個別選取或移除。

## 頁首頁尾範本

先在左側選取要處理的頁面，再按工具列「頁首頁尾範本」。輸入範本名稱、文字、六種頁首或頁尾位置之一及字級；按「儲存範本」後可在之後的文件中直接選用，也可以覆寫同名範本或刪除不用的範本。

文字中的 `{page}` 會在套用時換成該頁於整份文件中的實際頁碼，`{pages}` 會換成文件總頁數。例如 `內部文件  第 {page} / {pages} 頁` 在三頁文件的第二頁會顯示為「內部文件 第 2 / 3 頁」。按「套用到選取頁面」會立即寫入所有選取頁面，並可用 `Ctrl+Z` 復原；不必先儲存範本也能直接套用目前設定。

## 標記與註解

要加螢光標記或底線，先在中央頁面點選文字。若沒有修改內容，點到工具列時原文不會被重寫，選取範圍會保留；接著開啟「標記註解」，選擇「螢光標記」或「加底線」，效果會直接寫入目前頁面。

要新增文字註解，開啟「標記註解」並選擇「文字註解」，再點頁面上的放置位置，輸入內容後按確定。註解使用 PDF 原生格式，可由支援標準 PDF 註解的閱讀器辨識。標記與註解均可用 `Ctrl+Z` 復原或 `Ctrl+Y` 重做。

要管理既有註解，開啟「標記註解」並選擇「選取註解」，再直接點頁面上的螢光、底線或文字註解。紫色虛線框表示目前選取項目；按 `Delete` 或選擇「刪除選取註解」即可立即刪除，不需再確認。

選取螢光標記後，可從同一選單直接切換黃色、綠色、粉紅色或藍色。顏色會立即寫入 PDF；底線及文字註解不會啟用螢光色選項。

## 合併與拆分

合併視窗可加入多份 PDF，拖曳頁面排序或移除選取頁面。輸出前確認順序。

拆分每行是一份檔案，例如第一行 `1-3`、第二行 `5`。同一行 `1,3,5-7` 會產生一份包含這些頁面的 PDF。也可按固定頁數拆分。先預覽檔名及頁數，再輸出；已存在的同名檔案不會被默默覆寫。

重組頁面不重建書籤及文件內部連結。具有表單、簽章或附件的文件禁止合併拆分。

## 保留資料與復原

Ctrl+Z 復原、Ctrl+Y 重做，最近 30 次操作有效。關閉工作階段後歷史不保留。另存預設加上「-已編輯」，不能覆寫來源路徑。

遇到密碼文件先輸入密碼。程式遵守文件修改權限；另存不保留加密，操作時會提示。既有表單及憑證簽章文件僅供閱讀。

收藏資產位於 Qt 的本機應用程式資料目錄下 `assets`，頁首頁尾範本保存在同一資料目錄的 `header-footer-templates.json`。工作快照位於 `%LOCALAPPDATA%/LocalPDFEditor/sessions`，正常結束即清理，異常結束在下次啟動清理。解除安裝保留收藏資產與範本。

## 版本限制

本版不包含 OCR、Office 轉檔、表單建立、原圖編輯、全文自動排版、憑證簽署或 Adobe Acrobat 全功能相容性。裁切調整可見範圍，不會安全抹除範圍外的原始內容。建議先用文件副本測試實際版面。候選版本的驗證範圍詳見驗收紀錄。
