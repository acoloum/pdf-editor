# 墨頁 PDF 0.19.0

供 Windows 11 x64 使用的本機 PDF 編輯器。文件不會上傳，也不需帳號。

## 安裝與啟動

執行安裝程式，安裝至目前使用者的程式目錄。安裝時可勾選「將墨頁 PDF 加入 PDF 檔案的『開啟方式』清單」（預設勾選）與「建立桌面捷徑」；加入開啟方式清單不會變更系統目前的預設 PDF 程式，可在檔案總管對 PDF 按右鍵選「開啟方式 → 墨頁 PDF」。從開始功能表開啟「墨頁 PDF」，也可將 PDF 路徑當作程式命令列參數開啟。

開啟文件的方式：

- 按工具列「開啟 PDF」（`Ctrl+O`）。
- 把 PDF 從檔案總管直接拖進視窗（頁面區或左側縮圖列皆可）。
- 按「開啟 PDF」右側的小箭頭，從「最近開啟的檔案」清單選擇（保留最近 10 份，已不存在的檔案會自動移除）。

程式會記住視窗大小、左右面板寬度、縮放模式與最後使用的資料夾，下次開啟時自動還原。

## 介面配置

- **工具列**依用途分組：檔案（開啟、另存、列印）｜復原、重做｜編輯（新增文字、標記註解、蓋章、手寫簽名）｜頁面（頁面操作、合併、拆分、頁碼／浮水印、頁首頁尾）｜工具（OCR、頁面比較、搜尋）。「蓋章」右側箭頭內含「常用圖章」與「轉換既有圖章」。滑鼠停在按鈕上會顯示功能說明與快捷鍵。
- **左側**有「頁面」與「書籤」兩個分頁。書籤分頁會讀取 PDF 內建目錄，點選項目即跳到對應頁面；文件沒有目錄時會顯示提示。
- **右側**未選取任何物件時顯示「文件資訊」：檔名、位置、頁數、紙張尺寸、頁面旋轉、本頁字型、PDF 版本、檔案大小、編輯權限與密碼保護狀態。點選文字或圖章後會切換為對應的編輯面板。
- **狀態列**左側顯示操作訊息；右側依序為游標所在的 PDF 座標（點）、目前頁面尺寸、未儲存標示（● 未儲存）、翻頁控制與縮放控制。

## 瀏覽與縮放

- 狀態列的翻頁按鈕依序為第一頁、上一頁、頁碼、下一頁、最後一頁；頁碼欄可直接輸入後按 `Enter` 跳頁。快捷鍵：`PageUp`／`PageDown` 上下頁，`Ctrl+Home`／`Ctrl+End` 第一頁／最後一頁。
- 用滑鼠滾輪捲到頁面最上方或最下方後再滾一格，會自動切換到上一頁或下一頁；整頁都在畫面內時，滾一格即翻頁。
- 按住 `Ctrl` 滾動滑鼠滾輪可逐級縮放；也可按狀態列的「－／＋」或 `Ctrl+-`、`Ctrl++`。縮放選單可選「適合頁面」或「適合寬度」，範圍為 25% 至 500%。逐級縮放會維持目前檢視區域的中央位置。

## 搜尋

按 `Ctrl+F` 或工具列「搜尋」，畫面右上角會出現浮動搜尋列。輸入文字後按 `Enter`，程式會搜尋整份文件，以黃色方框標示目前結果，並顯示「目前筆數 / 總筆數」。按 `F3` 前往下一筆，按 `Shift+F3` 返回上一筆；跨頁結果會自動切換頁面。按 `Esc` 或「✕」關閉搜尋列並清除標示。搜尋以 PDF 中可擷取的文字為準；純影像掃描頁可先用內建 OCR 建立文字層。

## 複製文字與右鍵選單

- 點選頁面上的文字後按 `Ctrl+C` 複製該段文字；按 `Ctrl+Shift+C` 複製目前頁面的全部文字（依閱讀順序）。
- 在頁面上按右鍵：可複製游標下的文字、複製本頁全部文字、在此新增文字或文字註解、使用頁面操作、縮放與列印。
- 在左側縮圖按右鍵：直接開啟頁面操作選單（上移、下移、旋轉、複製、插入、抽取、匯出、裁切、刪除）。

## 列印

按工具列「列印」或 `Ctrl+P`，會先開啟程式內的「預覽列印」視窗，可檢視每頁實際列印的樣子（含圖章與簽名），並切換直印／橫印、縮放、單頁／雙頁／全部頁面檢視，或按齒輪圖示調整紙張設定。確認無誤後按右上角印表機圖示，再於 Windows 列印對話框選擇印表機、份數與列印範圍（全部、目前頁面或指定頁碼）。

Windows 11 的列印對話框只會替商店類型程式顯示預覽，一般桌面程式會出現「此應用程式不支援預覽列印」，這是系統限制；請改用墨頁 PDF 的預覽列印視窗確認版面。

每頁以最高 300 DPI 輸出並等比例置中（預覽在頁數較少時與實際列印同為 300 DPI，放大檢視仍清晰；頁數很多時會自動降低預覽解析度以節省記憶體），頁面方向與紙張方向不同時會自動旋轉。產生頁面期間可按「取消」中止。

## 儲存

- **儲存（`Ctrl+S`）**：直接覆蓋原檔。第一次使用時會顯示確認視窗，可勾選「以後不再詢問」。
- **另存新檔（`Ctrl+Shift+S`）**：在「儲存」按鈕右側的箭頭選單中，或用快捷鍵；原始檔案不會被覆蓋。
- 覆蓋時會先寫入暫存檔並驗證頁數與可正常顯示後，才原子取代原檔；中途失敗不會留下半個檔案，但原檔內容會被這次的編輯結果取代，程式不會另外保留原檔副本。
- 原檔已被移走或刪除時，「儲存」會改為詢問另存位置。
- 有密碼保護的文件，覆蓋或另存後都不會保留密碼保護，儲存前會再次確認。

## 錯誤紀錄

發生錯誤時會顯示說明對話框。未預期的錯誤會寫入紀錄檔 `%LOCALAPPDATA%\LocalPDFEditor\logs\pdf-editor.log`，回報問題時請一併提供。縮圖產生失敗時，該頁縮圖會顯示錯誤圖示（滑鼠停留可看原因），頁面本身仍可正常檢視與編輯。

## 修改文字

1. 按「開啟 PDF」並選擇文件。
2. 在中央頁面點選一個橫排文字區段。
3. 青色框輸入欄會直接出現在原文字位置，字的大小與目前頁面縮放一致；輸入新內容後按 `Enter`，或點到欄位外，就會立即寫入頁面。按 `Shift+Enter` 可換行。
4. 按 `Esc` 取消本次輸入。把內容清空後按 `Enter` 或點到欄位外，即刪除該段文字。
5. 套用後文字會保持選取，右側可繼續調整字級、文字框、字型、顏色、粗體與對齊方式；選取狀態下按 `Enter`、`F2` 或再點一次文字，可再次修改內容。

**文字變長時自動調整**

- 一般文字：文字框會自動向右加寬（置中文字向兩側加寬），多行時向下加高，但不會跨過旁邊的文字或頁面邊界。
- 表格儲存格：維持儲存格大小，自動縮小字級，最多縮到原字級的 70%。
- 真的放不下時，輸入欄會保留你打好的內容並顯示紅框，旁邊說明需要多少空間、還剩多少空間，直接修改文字後再按 `Enter` 即可，不必重新輸入。
- 若與其他文字重疊，衝突的文字會以紅色虛線框標出。

**保留原本的樣式**

- 原文字為粗體時，「粗體」會自動勾選；中心點位於頁面正中央的標題會自動設為「水平置中」，改字後維持置中。
- 字型：能沿用原字型時直接使用；原字型無法使用或缺字時，會依原字型風格改用相近的系統字型（例如 Times New Roman／新細明體等明體類、Arial／微軟正黑體等黑體類、標楷體），都找不到才使用內建 Noto Sans CJK TC。右側會顯示實際使用的字型。
- 也可從字型下拉選單選擇內建 Noto Sans CJK TC 或系統已安裝字型，或按「選擇字型檔…」挑選 .ttf/.otf 字型檔。
- 粗體會優先使用同一字型家族的真實粗體檔（如微軟正黑體 Bold、Times New Roman Bold）；內建 Noto Sans CJK 等沒有粗體檔的字型改以描邊模擬，墨水量約增加 65%，與真實粗體相當。
- 字型缺少目前文字的部分字元時，側邊欄會即時顯示「此字型缺少部分字元：…」。

**右側數值欄位**

字級與文字框座標在按 `Enter`、離開欄位，或停止點選上下箭頭約 0.4 秒後才套用，不會每按一下就寫入文件一次。字型、顏色、粗體與對齊方式選擇後立即套用。

6. 按「儲存」（`Ctrl+S`）覆蓋原檔，或用「另存新檔」（`Ctrl+Shift+S`）另存一份。

選取文字後按 `Delete` 可清空該段文字；頁面原位置會立即出現輸入欄，可直接輸入替代內容。也可按工具列「新增文字」或 `Ctrl+T`；按鈕保持選取且頁面顯示青色提示時，點選空白儲存格或頁面位置，中央頁面會出現輸入欄。按 `Esc` 可取消新增模式或目前輸入。所有已套用的操作都可用 `Ctrl+Z` 復原。

按住文字拖曳會立即移動並套用文字；按住頁面空白處拖曳可平移頁面。選取表格文字時，程式會自動使用偵測到的儲存格範圍作為文字框，並預設水平及垂直置中。部分 PDF 會把每個中文字拆成不同字型片段，程式會將同一行片段合併成可編輯文字。

文字框的單位是 PDF 點（72 點為 1 英吋）。此版本支援局部橫排文字，直排、斜向字、無法解碼的字，以及原有未套用遮蔽標記的頁面不支援修改。

## 圖章與簽名

「蓋章」匯入透明 PNG，亦可匯入簽名 PNG；「手寫簽名」提供滑鼠書寫。按「常用圖章」可重用已收藏圖章。

加入圖章或簽名後，選取項目會出現外框及四個角落控制點。控制點的整個白色方塊都可抓取；拖曳圖章本體可移動位置，拖曳任一角落控制點可直接放大或縮小，並自動維持原始長寬比例。放開滑鼠後會立即套用並同步更新右側數值，不需手動輸入長度與寬度。右側欄位保留作為精確位置、尺寸及旋轉角度的微調工具。

圖章會自動收藏；手寫簽名只有勾選收藏才永久保存。簽名是頁面外觀，不是憑證數位簽章。另存時，畫面可見的圖章與簽名會寫入 PDF 內容，程式也會在檔案內保存乾淨基底、圖章資產及位置資料。使用「墨頁 PDF」關閉再重開同一份另存檔後，這些圖章仍可單獨選取、移動、縮放、旋轉、復原及重做，再次另存也不會在舊位置留下重影。

若圖章已經固定在舊 PDF 頁面中，可按工具列「轉換既有圖章」。程式會在背景掃描整份文件，列出可安全抽離的影像縮圖；選取正確的縮圖後，按「轉換為可編輯圖章」，即可在頁面上移動或調整它，並可用 `Ctrl+Z` 復原、`Ctrl+Y` 重做。轉換只處理在整份文件中使用一次、只有一個放置位置，且面積小於頁面 90% 的單一影像。為避免誤改文件，整頁掃描、跨頁或重複使用的 Logo／影像，以及由線條或文字組成的向量章都不會列為候選；沒有候選時，原文件不會被變更。

可編輯工作層是「墨頁 PDF」附加在另存檔中的專用資料。一般 PDF 閱讀器仍會看到已寫入頁面的圖章，但第三方的壓縮、最佳化、列印成 PDF 或移除附件功能可能刪除工作層；之後再用本程式開啟時，圖章仍看得到，卻只能當成靜態頁面內容。工作層資料若毀損或驗證失敗，程式也會安全地以靜態 PDF 開啟並顯示提示，不會套用不完整的可編輯圖章資料。

## 頁面操作

先在左側縮圖選取頁面，再開啟工具列的「頁面操作」選單。按住 `Ctrl` 點選可逐頁加入或取消選取；先點第一頁，再按住 `Shift` 點另一頁，可選取連續範圍。選單可對全部選取頁面執行上移、下移、向左旋轉、向右旋轉、複製、裁切及刪除。批次移動會維持選取頁面彼此的順序，每次向指定方向移動一格。

選取單頁或多頁後，可在左側按住其中一個選取縮圖，直接拖曳到新位置。多頁會視為同一組移動，並維持彼此原有順序；放開滑鼠後，頁面順序、縮圖、目前頁碼及選取範圍會立即同步更新。

「複製選取頁面」會依照原順序建立副本，插入最後一個選取頁面之後，並自動選取新副本。快捷鍵依序為上移 `Alt+Up`、下移 `Alt+Down`、向左旋轉 `Ctrl+Shift+Left`、向右旋轉 `Ctrl+Shift+Right`、複製 `Ctrl+D` 及刪除 `Ctrl+Delete`。頁面操作可用 `Ctrl+Z` 復原或 `Ctrl+Y` 重做。文件至少必須保留一頁，因此選取全部頁面時不會啟用刪除。

「新增空白頁」會在最後一個選取頁面後方加入一頁，頁面尺寸與旋轉方向會沿用該頁，新增後自動跳到空白頁。「插入另一份 PDF（全部頁面）」會把所選外部 PDF 的全部頁面插在最後一個選取頁面後方；支援輸入來源 PDF 密碼，插入後自動選取新增頁面。這兩項操作都會進入目前文件的復原歷史。

「抽取選取頁面另存」會依左側頁面順序建立獨立 PDF。抽取結果包含目前尚未另存的文字、圖章及簽名變更，但不會修改目前文件，也不會改變其復原歷史。若輸出檔已存在，程式會要求更換檔名，避免直接覆寫。

「匯出選取頁面為 PNG」會把左側選取頁面逐頁輸出為圖片，包含目前尚未另存的文字、圖章及簽名變更。選擇資料夾後可設定 72 至 600 DPI；預設為 150 DPI。檔名保留文件中的實際頁碼，例如選取第 1、3 頁時會產生「文件名-第001頁.png」及「文件名-第003頁.png」。只要其中一個目標檔已存在，本次輸出就會停止，避免覆寫舊檔；輸出圖片不會修改目前文件或復原歷史。

選擇「直接拖曳裁切框」後，中央頁面會顯示青色裁切框與八個控制點。拖曳任一邊線或四角，放開滑鼠便會把相同裁切範圍套用至進入模式時選取的全部頁面；按 `Esc` 可取消而不修改文件。拖曳框內部可整體移動目前裁切範圍。

需要指定固定數值時，可選擇「精確輸入裁切邊距」，輸入左、上、右、下邊距；單位是 PDF 點。裁切後寬度與高度至少保留 10 點。兩種裁切方式都只調整 PDF 的可見頁面範圍，原本位於範圍外的內容不會顯示，並可用 `Ctrl+Z` 復原。

若文件內還有可個別調整的圖章或簽名，頁面操作會先把它們固定至 PDF，再進行排序、旋轉或刪除，以避免位置錯亂。立即復原可回到圖章或簽名仍可個別調整的狀態。

## 頁碼與浮水印

先在左側選取要處理的頁面，再按工具列「頁碼／浮水印」。

「頁碼」可設定起始號碼、前置文字、後置文字、字級，以及頁首或頁尾的靠左、置中、靠右位置。非連續頁面會依目前選取頁面的先後順序連續編號。

「文字浮水印」可輸入文字並設定字級、不透明度及旋轉角度；程式使用內建繁中文字型產生置中的透明浮水印。「圖片浮水印」支援 PNG、JPG 及 JPEG，可設定相對頁面寬度、不透明度與旋轉角度，圖片會保持比例並置中。

頁碼與浮水印只套用至左側選取頁面，每次套用都會立即寫入目前工作階段，並可用 `Ctrl+Z` 復原。另存後會固定在 PDF 頁面中，重新開啟時不保證能個別選取或移除。

## 頁首頁尾範本

先在左側選取要處理的頁面，再按工具列「頁首頁尾範本」。輸入範本名稱、文字、六種頁首或頁尾位置之一及字級；按「儲存範本」後可在之後的文件中直接選用，也可以覆寫同名範本或刪除不用的範本。

文字中的 `{page}` 會在套用時換成該頁於整份文件中的實際頁碼，`{pages}` 會換成文件總頁數。例如 `內部文件  第 {page} / {pages} 頁` 在三頁文件的第二頁會顯示為「內部文件 第 2 / 3 頁」。按「套用到選取頁面」會立即寫入所有選取頁面，並可用 `Ctrl+Z` 復原；不必先儲存範本也能直接套用目前設定。

## 標記與註解

要加螢光標記或底線，先在中央頁面點選文字。若沒有修改內容，點到工具列時原文不會被重寫，選取範圍會保留；接著開啟「標記註解」，選擇「螢光標記」或「加底線」，效果會直接寫入目前頁面。未先選取文字也可點選這兩項，程式會結束新增文字、文字註解、選取註解或裁切等衝突模式，並在狀態列提示先點選文字、再次選擇標記。無法安全替換內容的文字不會開啟文字輸入框，但仍可加入螢光標記或底線。

要新增文字註解，開啟「標記註解」並選擇「文字註解」，再點頁面上的放置位置，輸入內容後按確定。註解使用 PDF 原生格式，可由支援標準 PDF 註解的閱讀器辨識。標記與註解均可用 `Ctrl+Z` 復原或 `Ctrl+Y` 重做。

要管理既有註解，開啟「標記註解」並選擇「選取註解」，再直接點頁面上的螢光、底線或文字註解。紫色虛線框表示目前選取項目；按 `Delete` 或選擇「刪除選取註解」即可立即刪除，不需再確認。若尚未選取註解就按「刪除選取註解」，程式會自動進入選取註解模式。

選取螢光標記後，可從同一選單直接切換黃色、綠色、粉紅色或藍色。顏色會立即寫入 PDF；尚未選取註解時按任一螢光色會自動進入選取模式，選到非螢光註解時則會顯示說明。

## 合併與拆分

合併視窗可加入多份 PDF，拖曳頁面排序或移除選取頁面。輸出前確認順序。

拆分每行是一份檔案，例如第一行 `1-3`、第二行 `5`。同一行 `1,3,5-7` 會產生一份包含這些頁面的 PDF。也可按固定頁數拆分。先預覽檔名及頁數，再輸出；已存在的同名檔案不會被默默覆寫。

重組頁面不重建書籤及文件內部連結。具有表單、簽章或附件的文件禁止合併拆分。

## 保留資料與復原

Ctrl+Z 復原、Ctrl+Y 重做，最近 30 次操作有效。關閉工作階段後歷史不保留。另存預設加上「-已編輯」，不能覆寫來源路徑。

遇到密碼文件先輸入密碼。程式遵守文件修改權限；另存不保留加密，操作時會提示。既有表單及憑證簽章文件僅供閱讀。

收藏資產位於 Qt 的本機應用程式資料目錄下 `assets`，頁首頁尾範本保存在同一資料目錄的 `header-footer-templates.json`。工作快照位於 `%LOCALAPPDATA%/LocalPDFEditor/sessions`，正常結束即清理，異常結束在下次啟動清理。解除安裝保留收藏資產與範本。
