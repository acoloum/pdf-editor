# 建置說明

驗證環境：Windows x64、Python 3.12。執行依賴的精確版本見 requirements.lock。PySide6 6.8.3 已完成凍結版啟動驗證；不要直接升級 Qt 繫結而略過封裝 smoke test。

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.lock
.venv/Scripts/python.exe -m pip install -e . --no-deps
.venv/Scripts/python.exe -m pytest -q
.venv/Scripts/python.exe -m pdf_editor
./scripts/build.ps1 -InnoCompiler 'C:/Tools/Inno/ISCC.exe' -PythonExecutable '.venv/Scripts/python.exe'
```

安裝工具使用 Inno Setup 6.4.3，來源 https://github.com/jrsoftware/issrc/releases/tag/is-6_4_3 。先驗證下載執行檔的有效數位簽章。繁中語系檔固定為 `6ef32198ef1f7b7b375cd4b6b90896c2a58eb4c2`；該檔標示適用 6.5.0 以上，但本專案已以 6.4.3 實際編譯驗證相容。不要將未核對的新工具、翻譯或依賴版本直接取代鎖定版本。

封裝為目錄式，保留 Qt 動態函式庫及第三方授權。原始碼與安裝包一併交付。修改或再散布前閱讀 licenses/ 中的條款及第三方清單。
