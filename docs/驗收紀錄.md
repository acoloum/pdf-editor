環境：Windows 11 x64（10.0.26200）、Intel64 Family 6 Model 151、實體記憶體 8.3 GB。

- Python 3.12.10、PySide6 Essentials 6.8.3、PyMuPDF 1.28.2。
- `pytest -q`：116 項通過，0 項失敗，耗時 58.03 秒。
- 頁面底圖依 Windows 裝置像素比例直接渲染，避免二次放大或縮小；縮放尺寸及文字點選座標維持一致。
- 端到端測試涵蓋：選取文字、替換文字、加入圖章、另存、復原、重做、再次另存、拆分頁面及來源檔雜湊不變。
- 互動測試涵蓋：中央頁面內直接修改與新增文字、Enter 或點到別處立即寫入、Esc 取消、左鍵平移頁面、拖曳文字並立即套用、Delete 刪除後原位新增、可見的新增模式提示、三種文字對齊選項及表格儲存格偵測。
- 頁面管理測試涵蓋：`Ctrl` 不連續多選、`Shift` 連續範圍多選、單頁及多頁縮圖直接拖曳排序、拖放位置換算、群組相對順序保留、多頁批次上移／下移、多頁批次向左／向右旋轉、多頁批次複製及刪除、最後一頁保護、縮圖與頁碼同步，以及複製或刪除後復原頁面數量。
- 標記註解測試涵蓋：選取文字後寫入原生螢光標記或底線、在指定頁面座標加入原生文字註解、空白註解及未知標記型別的拒絕處理，以及介面操作後復原。
- 註解管理測試涵蓋：讀取頁面原生註解及位置、中央頁面點選、Delete 刪除、黃／綠／粉紅／藍四色切換、非螢光註解禁止改色，以及改色後復原。
- 圖層縮放測試涵蓋：選取圖章後顯示四角控制點、拖曳右下角直接放大、放開後送出新位置與尺寸，以及縮放前後維持原始長寬比例。
- 另存採新檔名，不允許覆寫來源；既有表單、憑證簽章、附件及禁止修改的文件會停止高風險操作。

## PDF 相容性

- PyMuPDF 產生的編輯結果可重新開啟並擷取文字。
- 使用實際文件 `115.01.02-2014-F.pdf` 驗證：同一行 354 個碎片文字區段可合併為 142 個可選取區段；「韋伯式(HW)」可在短列高儲存格內改為置中的「硬度」，且表格線保持完整。
- 實際主視窗流程驗證：文字拖曳後 X 座標確實向右移動；刪除後在中央頁面原位置直接輸入「硬度」，再用工具列新增「新增測試」，四次變更均進入可復原歷史。
- 以實際文件複製成三頁後驗證：頁面下移、順時針旋轉、刪除、復原與重做均成功；頁面操作前的圖章會先固定至 PDF，復原後可回到仍能個別調整的圖層狀態。
- 以同一份三頁文件驗證：將第一頁縮圖拖至最後一頁後，文件內容順序確實變為第 2、3、1 頁；在所選文字寫入螢光標記，並於頁面指定位置加入文字註解，重新開啟工作階段 PDF 後可讀到 `Highlight` 與 `Text` 兩種原生註解。
- 以實際三頁文件驗證：黃色螢光標記改為綠色後，重新讀取 PDF 的原生色彩值正確；文字註解可在中央頁面直接點選並按 Delete 移除，最後只保留改色後的螢光標記。
- 以實際文件驗證：頁面上的圖章可由四角控制點直接拖大，右側寬高同步更新且維持 2:1 原始比例；縮放後再執行頁面旋轉，圖章可正常固定至 PDF，復原後仍能回到可調整圖層。
- 以實際文件複製成三頁後驗證：可同時選取第一頁及第三頁，也可連續選取第二頁及第三頁；批次上移後實際內容順序變為第 3、1、2 頁，選取範圍同步移至新位置；批次旋轉只改變選取頁面；批次刪除後只保留未選頁面，復原可完整恢復。
- 以實際文件複製成三頁後驗證：不連續選取第一頁與第三頁並整組拖至末端，實際內容順序變為第 2、1、3 頁，選取範圍同步移至新位置；複製同一組後內容依序成為第 1、2、3、1、3 頁，新副本保持選取，復原可回到原三頁。
- 同一份文件連續新增不同中文字時會使用相符的獨立字型資源，實測「硬度」及「新增測試」皆可正確顯示與擷取。
- 內嵌子集字型在重新寫入前會檢查 Unicode 往返結果；不可靠時改用內建中文字型，避免顯示內容與文字層不一致。
- Poppler `pdftoppm` 以另一套 PDF 引擎渲染編輯後文件，結束代碼 0；渲染結果可見替換後文字「檢測合格 XYZ 789」，原有「品質檢驗 ABC 123」與「KEEP ME」仍存在。
- Poppler 對測試檔回報缺少 Symbol 顯示字型的提示，但輸出 PNG 正常，測試內容未使用 Symbol 字元。
- 尚未完成 Microsoft Edge 內建 PDF 閱讀器的自動化驗證；先前自動化工具無法可靠確認瀏覽器目前 URL，因此未把該次操作列為通過。

## 已知限制

- 文字修改適用於可解碼、局部、橫排文字；不提供 OCR、直排重排、斜向文字重排或全文自動排版。
- 圖章與簽名是寫入頁面的外觀，不是憑證數位簽章。
- 合併與拆分不重建書籤及文件內部連結。
- 已加密文件另存時不保留加密；程式會先提示。
- 此版本聚焦文字修改、蓋章、手寫或圖片簽名、合併及拆分，未宣稱完整重現 Adobe Acrobat 的所有功能。
