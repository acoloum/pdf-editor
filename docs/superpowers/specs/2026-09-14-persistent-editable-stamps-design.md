# 墨頁 PDF 可持久編輯圖章設計

日期：2026-09-14
目標版本：下一版

## 目標

讓墨頁 PDF 新增的圖章及簽名在「另存、關閉、重新開啟」後仍可選取、移動、縮放與刪除。同時提供安全的既有圖章轉換流程：使用者從程式列出的候選影像中選定目標後，將該影像轉為可持久編輯的圖層。

PDF 在其他閱讀器中的外觀必須與一般 PDF 相同；可編輯狀態只由墨頁 PDF 使用內嵌工作資料恢復。來源檔一律不直接覆寫。

## 使用流程

### 新增圖章與簽名

使用者以「蓋章」、「常用圖章」或「手寫簽名」加入圖像後，現有的拖曳、四角等比例縮放與右側精確輸入流程不變。另存的 PDF 會同時包含可見圖章與內嵌圖層資料。重開該 PDF 時，墨頁 PDF 自動載入圖層資料，並讓圖章再次顯示選取外框及控制點。

### 轉換既有圖章

新增「轉換既有圖章」動作。程式掃描文件中的影像物件，只顯示可安全抽離的候選項目：影像必須在整份文件中只使用一次，且在單一頁面只對應一個矩形。候選清單顯示頁碼、縮圖、位置及尺寸；使用者明確選取一項後才執行轉換。

轉換會保留圖像的原始位置與外觀，將它自乾淨頁面基底中移除，再建立對應的可編輯圖層。完成後立即選取新圖層。掃描整頁、重複使用的公司 Logo、多次繪製的影像、向量內容及無法安全抽離的影像不列入候選，並說明不支援原因；程式絕不猜測或自動修改這些內容。

## 資料格式與載入

每次另存時，程式產生兩個互補表示：

1. 一般 PDF 表示：以既有方式將所有圖層繪入頁面，供任何 PDF 閱讀器、列印與寄送使用。
2. 墨頁工作層：以命名的 PDF 內嵌檔案保存版本化 JSON 清單、各圖層 PNG 資產，以及未包含可編輯圖層的乾淨 PDF 基底。

工作層 JSON 包含格式版本、圖層 ID、頁碼、位置、旋轉角度及對應資產名稱。乾淨基底加上圖層資料是唯一可編輯的真實來源；可見 PDF 則是其輸出快照。這避免重開後把已繪入的章再次疊加，也避免多次另存產生重影。

開檔時先偵測並驗證工作層：JSON 結構、格式版本、資產雜湊、頁數及基底 PDF 都必須一致。驗證成功才以基底與圖層建立 `DocumentSession`；沒有工作層、工作層被其他軟體移除、版本不支援或驗證失敗時，照一般靜態 PDF 開啟，並在狀態列說明無法恢復可編輯圖章。

## 舊影像轉換與安全限制

舊檔沒有圖層識別資料，因此只能轉換符合安全條件的單一 PDF 影像 XObject。轉換程序先擷取原始影像與其矩形，建立副本，在副本中移除唯一影像參照，並重新渲染驗證移除後的基底。若無法確認影像只出現一次、移除後頁面不完整、輸出無法重新開啟，整個轉換取消且不修改工作階段。

轉換成功後，乾淨基底與抽出的 PNG 立即納入歷程。原圖位置由新的圖層繪製，畫面與轉換前一致；移動後不會留下舊圖像。使用者可用 `Ctrl+Z` 回到轉換前的靜態影像，也可用 `Ctrl+Y` 再次轉換。

## 元件邊界

- `persistent_overlays.py`：工作層格式、內嵌檔案讀寫、驗證、基底與資產封裝。
- `legacy_overlay_conversion.py`：候選影像掃描、縮圖、單次使用驗證、影像抽離與轉換交易。
- `model.py`：工作層描述與候選影像資料模型。
- `document/session.py`：開檔時優先載入已驗證的工作層，並維持既有復原歷程語意。
- `document/save.py`：輸出可見 PDF 與內嵌工作層；保留現有檔案驗證與原檔保護。
- `ui/main_window.py` 與新對話框：新增轉換動作、候選選擇、背景工作、狀態及錯誤訊息。
- `ui/canvas.py`：沿用既有 `Overlay` 選取、拖曳與縮放互動，不複製第二套編輯行為。

## 錯誤處理

所有解析、轉換與儲存均先在記憶體或暫存檔完成，再一次提交工作階段或輸出檔。下列情況必須保留現有內容並使用繁體中文說明：工作層毀損或版本不支援、資產雜湊不符、影像重複使用、影像為整頁掃描、影像抽離失敗、PDF 驗證失敗，以及目標檔寫入失敗。

## 測試與驗收

- 新增圖章後另存、關閉及重開，確認圖層仍可移動、縮放、刪除及復原。
- 多次另存、重開、再另存後，驗證每一頁只出現一個圖章且位置正確。
- 以唯一嵌入的 PNG 模擬既有統編章，轉換後確認原位置外觀相同，移動後舊位置不殘留，重開後仍可編輯。
- 確認重複使用影像、整頁掃描與非影像內容不列入候選，且不改變文件。
- 移除或竄改工作層後開檔，確認文件以靜態 PDF 正常顯示並提示原因。
- 以 PDF 渲染圖像比對轉換前後及外部可見輸出，確認圖章、表格、頁碼及留白沒有裁切、重影或位置偏移。

## 限制

舊檔轉換不會辨識向量章、掃描頁中的章、與其他內容共用同一影像物件的圖樣，或已被其他內容覆蓋的影像。這些情況必須以重新蓋章處理。若 PDF 經第三方軟體重新最佳化並移除內嵌工作層，仍保留可見章，但不再能恢復為可編輯圖層。
