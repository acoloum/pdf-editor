# 墨頁 PDF OCR 與頁面比較設計

日期：2026-09-12  
目標版本：0.14.0

## 目標

本版加入兩項完全離線功能：將掃描頁面轉成可搜尋、可反白及可複製文字的 OCR 文字層，以及比較目前頁面與另一份 PDF 指定頁面的視覺差異。兩項功能皆沿用現有背景工作、錯誤提示、密碼處理與工作階段機制。

## OCR 使用流程

使用者先在左側選取一頁或多頁，再按工具列「OCR 文字辨識」。程式直接以繁體中文及英文、300 DPI 辨識選取頁面，不再要求設定長串參數。辨識期間停用會衝突的編輯操作，並在狀態列顯示處理頁數；完成後顯示成功及跳過頁數。

每頁若已有至少十個可擷取的非空白字元，預設視為已有文字層並跳過，以免重複文字。掃描頁會先以 300 DPI 渲染，再交給隨程式封裝的 Tesseract 與 `chi_tra+eng` 快速語言模型。程式透過 `tesserocr` 讀取 Tesseract TSV 的單字位置與信心值，忽略空白及低信心結果，將像素座標換算成 PDF 點後，以不可見文字寫回原頁。原始圖像與頁面尺寸保持不變。

OCR 完成會建立一筆工作階段歷史，因此可用 `Ctrl+Z` 復原及 `Ctrl+Y` 重做。另存後文字層保存在新 PDF；既有全文搜尋會直接找到 OCR 文字。OCR 不修改來源檔，除非使用者另存新檔。

若 OCR 引擎或語言模型缺失、引擎逾時、沒有任何可接受結果，程式顯示繁體中文錯誤訊息且不提交半成品。多頁辨識先在記憶體中的副本完成，全部成功後才一次套用至工作階段。

## OCR 封裝與授權

Windows 安裝程式包含 `tesserocr 2.10.0` 所附的 Tesseract 5.5.2 與必要動態函式庫，以及官方 `tessdata_fast` 的繁體中文與英文模型。建置腳本驗證下載檔雜湊；第三方清單記錄版本、來源及授權，並把相應授權文字放入安裝內容。執行時只使用封裝內容，不讀取電腦上其他 Tesseract 安裝。

OCR 核心模組只接受 PDF 位元、頁碼、語言資料路徑與可替換的引擎工廠，回傳新 PDF 位元及逐頁結果。Tesseract 透過 Python 原生繫結在背景工作程序執行；測試以假的引擎工廠提供固定 TSV，不依賴實際辨識結果。

## 頁面比較使用流程

使用者開啟基準 PDF 並切到要比較的頁面，再按工具列「頁面比較」。程式要求選擇另一份 PDF；若檔案加密則要求密碼。比較視窗開啟後，可用頁碼欄切換比較文件頁面。

視窗以三欄呈現「目前頁面」、「比較頁面」及「差異」。目前頁面包含尚未另存的文字、圖章與簽名；比較文件保持唯讀。兩頁以 144 DPI 渲染成白底 RGB 圖像，比較頁等比例縮放並放在與基準頁相同大小的白色畫布中央。差異算法先轉灰階，將每像素差值不超過 24 的輕微反鋸齒差異視為相同；超過門檻的位置在基準頁上以半透明紅色標示。

相似度定義為未超過門檻的像素數占整張比較畫布像素數。若頁面尺寸或比例不同，畫布留白區也納入差異。視窗顯示百分比至小數點後一位，並顯示基準頁與比較頁頁碼。三張圖以相同顯示比例縮放，保留各自捲動區域；比較不修改工作階段及復原歷史。

## 元件邊界

- `ocr.py`：引擎定位、頁面渲染、TSV 解析、座標換算及不可見文字層寫入。
- `comparison.py`：頁面渲染、對齊、差異遮罩、相似度及預覽圖產生。
- `comparison_dialog.py`：三欄預覽、比較頁碼切換及結果說明。
- `main_window.py`：工具列動作、檔案及密碼選擇、背景工作與工作階段提交。
- 封裝設定與授權清單：包含 OCR 執行檔、語言模型、來源、版本及授權。

## 測試與驗收

OCR 測試先以假的引擎輸出驗證 TSV 解析、信心門檻、像素至 PDF 座標換算、已有文字頁跳過、無結果與引擎錯誤時不提交，以及 OCR 後可搜尋、反白及復原。另以實際封裝引擎辨識高對比繁中與英文掃描頁，重新開啟 PDF 後確認可擷取指定文字。

頁面比較測試驗證相同頁為 100%、單一區塊改動會降低相似度並產生紅色遮罩、微小反鋸齒差異被忽略、不同頁面尺寸正確置中，以及比較前後工作階段版本不變。介面測試驗證工具列動作、比較頁碼切換、三欄圖像與相似度文字。

正式驗收使用現有原版材料報告：先產生純影像掃描副本並執行 OCR，確認主要標題可搜尋；再用原版與局部修改副本執行頁面比較，確認修改區域出現在紅色差異圖。最後建立 Windows 安裝程式，在隔離目錄安裝並執行兩項功能後解除安裝，確認無殘留程序與安裝目錄。

## 限制

OCR 首版支援水平繁體中文與英文，辨識品質取決於掃描解析度、傾斜、污漬及字型；不提供手寫字辨識、表格結構重建或自動校正文句。頁面比較是像素比較，不判斷文字語意；頁面位置偏移或大幅縮放會被視為差異。
